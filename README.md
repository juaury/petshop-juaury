# Petshop-3-huellas - E-commerce React

Proyecto de e-commerce desarrollado con React y Vite.

## Tecnologías

- React
- Vite
- JavaScript
- Firebase Firestore
- CSS

## Instalación

Clonar el repositorio:

```bash
git clone NOMBRE_DE_TU_REPOSITORIO
Instalar dependencias:

npm install

Ejecutar el proyecto:

npm run dev
Variables de entorno

El proyecto utiliza variables de entorno para la conexión con Firebase.

Crear un archivo .env en la raíz del proyecto con las siguientes variables:

VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=

El archivo .env no se incluye en el repositorio por seguridad.

Funcionalidades
Visualización de productos
Carrito de compras
Gestión de productos
Formularios de contacto
Base de datos con Firebase Firestore
